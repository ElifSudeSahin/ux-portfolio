## Selected Projects

### 01 — Politecnico di Torino Website: Heuristic Evaluation

**UX Research · Usability Evaluation · Nielsen's Heuristics**

[View Case Study](https://github.com/ElifSudeSahin/ux-portfolio/tree/main/01-heuristic-evaluation)

An independent usability evaluation of the Politecnico di Torino website, focusing on the experience of an international prospective master's student navigating university information.

**Research Focus**

How effectively does the university website support users in finding relevant information and completing their goals?

**What I Explored**

- Evaluating an existing interface using Nielsen's 10 Usability Heuristics.
- Identifying usability issues related to navigation, information architecture, and content discoverability.
- Documenting usability findings with screenshots and severity assessments.
- Examining how interface structure can influence the efficiency and clarity of information-seeking tasks.
- Proposing directions for improving the user experience.

**Approach:** Heuristic Evaluation, UX Analysis, Usability Inspection

**Project Type:** Independent UX Case Study

### 02 — MindfulFeed: Designing Social Media Interfaces That Respect User Attention

**Human-Computer Interaction · Digital Wellbeing · UI Design · HTML/CSS**

[Live Demo](https://elifsudesahin.github.io/mindful-feed/) | [GitHub Repository](https://github.com/ElifSudeSahin/mindful-feed)

MindfulFeed is an independent, research-informed HCI design exploration investigating how social media interfaces might support more intentional browsing and greater user control.

The project is inspired by the *Digital Attention Heuristics* research by Alberto Monge Roffarello, Luigi De Russis, and Kai Lukoff (2025).

**Research Question**

*How might social media feed interfaces be redesigned to support more intentional browsing and greater user control?*

**What I Explored**

- Comparing a conventional attention-capturing feed with a mindful alternative.
- Applying four Digital Attention Heuristics: Agency, Informed Usage, Balanced Usage, and Customization.
- Exploring interface alternatives to autoplay, endless loading, and attention-grabbing notifications.
- Designing clearer feed boundaries, content labels, and session information.
- Documenting design decisions, limitations, and possible future evaluation methods.

**Prototype**

The project includes two vertically scrollable social media feed mockups built with HTML and CSS. A comparative analysis explains the rationale behind the proposed design changes.

The prototype is primarily static, and its effectiveness has not been evaluated through user testing.

**Approach:** Research-Informed Design, Comparative Prototyping, UX Analysis

**Technologies:** HTML, CSS

**Project Type:** Independent HCI Design Exploration
